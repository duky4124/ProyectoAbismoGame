# PROYECTO ABISMO — Capítulo 1: EL ACCIDENTE

Juego de terror y supervivencia en 3D, primera persona (Three.js + React + Vite + Tailwind).
Todo el contenido (texturas, modelos, música y sonidos) es procedural y original → sustituible por assets definitivos.

## Ejecutar
```
npm install
npm run dev      # desarrollo
npm run build    # genera dist/index.html (archivo único, jugable offline)
```
Para obtener un ejecutable de Windows, empaqueta `dist/index.html` con Electron o Tauri (`electron-builder --win`).

## Controles
WASD mover · ratón mirar · Shift correr · C agacharse · Espacio saltar · F linterna · E interactuar/esconderse ·
Tab mochila/fabricación/archivo · G lanzar distractor · Q curarse · Esc pausa · R reintentar al morir.
Móvil: joystick izquierdo (empujar al borde = correr), arrastrar a la derecha para mirar, botones en pantalla.

## Capítulo 1 (completo)
Linterna → objetos y fabricación (palanca, distractor, fusible, botiquín) → salir del hangar (puerta o conducto) →
código de Seguridad (pistas en oficinas: 1403) → tarjeta → persecución del Observador → fusible en la esclusa →
llamar al ascensor y sobrevivir → decisión final. Hay sala secreta (palanca oculta en el Almacén B) y documentos opcionales.
Capítulos 2–10 aparecen bloqueados: están en desarrollo (motor y sistemas ya preparados para añadirlos).
